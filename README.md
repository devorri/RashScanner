# Rashilience — Edge Multimodal Clinical Decision Support System

An edge-ready, offline-capable Python web application for Raspberry Pi 4 equipped with a camera module. The project combines **MobileNetV2 Transfer Learning Computer Vision** with **Clinical Symptom Matching** into a 50/50 Multimodal Fusion Engine, complete with an **Admin Portal**, **Patient Clinical Intake Form**, and **SQLite Database**.

---

## 🌟 Key Features

- **Web Portal & Admin Dashboard**: Complete clinical interface with Admin authentication (`admin` / `admin123`).
- **Dual Image Acquisition**: Supports both **"Upload Image"** (file upload) and **"Use Live Camera"** (Raspberry Pi `picamera2` / OpenCV stream).
- **Patient Clinical Assessment Form**: Standardized medical intake fields matching full clinical requirements (Administrative, Demographics, Duration/Onset, History, General Inspection, Assessment, Management Plan).
- **Edge Computer Vision**: Pre-trained **MobileNetV2** model fine-tuned on 75 skin condition categories (~3,700 images) and exported to optimized **TensorFlow Lite (`rash_model.tflite`)**.
- **50/50 Multimodal Fusion Engine**:
  $$\text{Final Match Score} = (0.50 \times \text{Visual Model Prob}) + (0.50 \times \text{Symptom Match Score})$$
- **Persistent SQLite Database (`patients.db`)**: Saves patient intake details, uploaded/captured rash photos, AI multimodal diagnostic rankings, primary & differential diagnoses (DDx 1, 2, 3), and treatment plans.
- **Safety Red-Flag Detector**: Scans symptoms for critical warnings (high fever, breathing difficulty, skin peeling, unbearable pain) and alerts clinicians.

## 🌐 Running the Web Application Portal

### 1. Start Web Server
Run `app.py` on your local PC or Raspberry Pi:
```bash
python app.py
```
> Server starts at: **`http://localhost:5000`**

### 2. Access Web Interface
Open your web browser and navigate to `http://localhost:5000`:
- **Admin Login**:
  - **Username**: `admin`
  - **Password**: `admin123`

### 3. Patient Clinical Assessment Workflow
1. Fill out **Administrative Details** and **Patient Demographics**.
2. Select **Rash Duration**, **Onset**, **Pattern**, **Progression**, and enter **Associated Symptoms**.
3. Choose Image Acquisition method:
   - **Upload Image**: Drag & drop or browse a rash photo from your device.
   - **Use Pi Camera**: Click to take a live picture directly from the Raspberry Pi camera module.
4. Click **"Run AI Multimodal Analysis"**:
   - Executes `rash_model.tflite` + `symptoms_db.py` 50/50 fusion engine.
   - Displays Top 10 Ranked Match list with percentage breakdown.
   - Automatically pre-populates **Primary Diagnosis** and **Differential Diagnoses (DDx 1, 2, 3)**!
5. Complete **Management Plan** (Investigations, Treatment, Referral) and click **"Save Patient Assessment Record"**.

### 4. Admin Dashboard Features
- Click **"Admin Dashboard"** in the top navigation bar.
- View all saved patient assessment records in an interactive data table.
- Search patient records by name, diagnosis, or clinician.
- Click **"View"** to open a full printable clinical report modal containing patient details, rash image, AI rankings, and treatment plan.

## 🍓 Raspberry Pi 4 Edge Deployment

### 1. Enable Camera Hardware
On Raspberry Pi OS:
```bash
sudo raspi-config
# Navigate to: Interface Options -> Camera -> Enable
sudo reboot
```

### 2. Install Dependencies on Pi 4
```bash
sudo apt update && sudo apt install -y python3-opencv python3-libcamera python3-kmsxx
pip3 install flask tflite-runtime numpy opencv-python
```

### 3. Launch Web Server on Pi 4
```bash
python3 app.py --host 0.0.0.0 --port 5000
```
Access the scanner portal from any tablet, PC, or smartphone on your local network at `http://<YOUR_PI_IP>:5000`.
